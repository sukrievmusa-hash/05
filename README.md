# Hinoki SPA — онлайн-запись и CRM

Прототип для SPA-салона **Hinoki SPA** (Астана, пр. Б. Момышулы, 2А · @hinoki.spa).

- **Клиент:** меню услуг с фильтрами, пошаговая онлайн-запись с проверкой свободных слотов (хаммамы, мастера, чайная), подтверждение в WhatsApp, конструктор сертификата, контакты. RU / KZ.
- **CRM:** дашборд дня, шахматка 11:00–00:00 по ресурсам, статусы, алерты о пересечениях, теги интенсивности, ручная запись, база клиентов с LTV.

`index.html` — готовый самодостаточный файл (React встроен, JSX скомпилирован, интернет не нужен).
`source/index.dev.html` — исходник с JSX; после правок пересобрать: `python3 source/build.py` (нужны esbuild, react@18, react-dom@18 из npm).

## Сервер
Данные хранятся в Supabase (проект `hinoki-spa`, Frankfurt).
- Посетители сайта видят только занятые интервалы (функция `get_busy`) и создают бронь через `create_booking` — сервер сам проверяет накладки и считает цену.
- CRM открывается только после входа администратора (Supabase Auth); таблицы защищены RLS, доступ есть только у пользователей из таблицы `admins`.
- Новые записи появляются в CRM в реальном времени.

Схема базы — в `source/supabase.sql`. Логин и пароль администратора в репозиторий не кладутся.
